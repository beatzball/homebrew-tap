# beatzball/homebrew-tap

Homebrew formulas for beatzball tools.

```sh
brew install beatzball/tap/preen
brew install beatzball/tap/swoop
```

| formula | what it is | source |
|---|---|---|
| `preen` | browse Markdown and diffs in the terminal | [beatzball/preen](https://github.com/beatzball/preen) |
| `swoop` | a keyboard launcher built the Unix way | [beatzball/swoop](https://github.com/beatzball/swoop) |

Each formula installs a tagged release from its project on GitHub.
