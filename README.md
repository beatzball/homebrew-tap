# beatzball/homebrew-tap

Homebrew formulas for beatzball tools.

```sh
brew tap beatzball/tap
brew install swoop
```

| formula | what it is | source |
|---|---|---|
| `swoop` | a keyboard launcher built the Unix way | [beatzball/swoop](https://github.com/beatzball/swoop) |

Each formula installs a released binary from its project's GitHub release
and is updated by that project's release workflow, so the file here is
generated: change it at the source, not here.
